Loops ​

In Bash, loops allow you to repeat a series of commands or instructions a certain number of times, or until a condition is met or stops being met.

for loop ​

The for loop is used to iterate over a list of elements. For each iteration, a different value from the list is assigned to a variable.

Basic syntax ​

bash
for variable in list; do
  # Commands to execute
done

Example: ​

bash
#!/bin/bash

for i in 1 2 3 4 5; do
  echo "Number: $i"
done

This example will print the numbers from 1 to 5.

Different ways to represent the list or set ​

  1. Explicit list: You can explicitly list the elements inside the loop.
bash
for fruit in apple orange banana; do
  echo "Fruit: $fruit"
done
  1. Numeric ranges: The {start..end} expansion is used to generate a range of numbers.
bash
for i in {1..10}; do
  echo "Number: $i"
done
  1. Ranges with increment: It is possible to specify an increment by adding {start..end..increment}.
bash
for i in {0..20..5}; do
  echo "Number: $i"
done
  1. List generated by a command: Commands can be used to dynamically generate the list of elements.
bash
for word in $(echo "Hello World in Bash"); do
  echo "Word: $word"
done
bash
for file in $(ls *.txt); do
  echo "File: $file"
done
  1. Elements of an array: If an array is used, the loop can iterate over its elements.
bash
fruits=(apple orange banana)
for fruit in "${fruits[@]}"; do
  echo "Fruit: $fruit"
done

Double parentheses in for loop ​

Bash also allows using a double parentheses syntax to handle numeric iterations similar to languages like C.

Example: ​

bash
#!/bin/bash

for ((i = 1; i <= 5; i++)); do
  echo "Number: $i"
done

This approach is useful for numerically controlled iterations and is more suitable for calculations or steps defined directly in the loop.

while loop ​

The while loop executes a block of code while a condition is true.

Basic syntax ​

bash
while [ condition ]; do
  # Commands to execute
done

Example: ​

bash
#!/bin/bash

counter=1

while [ $counter -le 5 ]; do
  echo "Counter: $counter"
  counter=$((counter + 1))
done

This example increments a counter from 1 to 5, printing its value in each iteration.

until loop ​

The until loop is similar to while, but executes the block of code while the condition is false.

Basic syntax ​

bash
until [ condition ]; do
  # Commands to execute
done

Example: ​

bash
#!/bin/bash

counter=1

until [ $counter -gt 5 ]; do
  echo "Counter: $counter"
  counter=$((counter + 1))
done

This example works the same as the while loop, but with the condition negated.

Infinite loop ​

Infinite loops are used when you want a block of code to repeat indefinitely until an event occurs or a command like break is used to stop it.

Example with while: ​

bash
#!/bin/bash

while true; do
  echo "This is an infinite loop."
  sleep 1
done

This loop will print the message every second indefinitely.

Example with for: ​

bash
#!/bin/bash

for (( ; ; )); do
  echo "This is an infinite loop using 'for'."
  sleep 1
done

Both approaches can be interrupted manually with CTRL+C or programmatically using break.

Loop control ​

break ​

The break command terminates a loop before it completes its execution.

Example: ​

bash
#!/bin/bash

for i in 1 2 3 4 5; do
  if [ $i -eq 3 ]; then
    break
  fi
  echo "Number: $i"
done

This example will print the numbers 1 and 2, but will stop when i equals 3.

continue ​

The continue command skips to the next iteration of the loop, omitting the remaining instructions of the current iteration.

Example: ​

bash
#!/bin/bash

for i in 1 2 3 4 5; do
  if [ $i -eq 3 ]; then
    continue
  fi
  echo "Number: $i"
done

This example will print the numbers 1, 2, 4, and 5, skipping 3.

Exercises ​

  1. Write a script that uses a for loop to print the numbers from 1 to 10.

  2. Write a script that uses a while loop to calculate the sum of the numbers from 1 to 100.

  3. Write a script that uses an until loop to count down from 10 to 1 and print each number.

  4. Write a script that implements an infinite loop with while and stops if the user enters "exit".

  5. Write a script that uses a for loop with double parentheses syntax to print the even numbers between 1 and 20.

  6. Write a script that implements an infinite loop with for and uses break to stop after five iterations.

  7. Write a script that uses a for loop to iterate over all files in the current directory and print their names.

  8. Write a script that uses a while loop to read a text file line by line, whose name will be entered by the user, and display each line on the screen.

  9. Write a script that uses a for loop to iterate over the results of a command, such as ls, and display each element found.

  10. Write a script that uses an until loop to continuously check if a specific file exists. The file name will be requested from the user, stopping when it is found.

  11. Write a script that implements an infinite loop with while. Ask the user for a directory and list its contents until they type "exit".

  12. Write a script that uses a for loop to iterate over a list of words. Ask the user for the words to search for and the directory where to search, using grep for each word.
