On this page

Functions ​

Functions in Bash allow you to encapsulate reusable blocks of code. They are useful for organizing scripts and avoiding redundancy when performing similar tasks.

Defining a function ​

In Bash, a function is defined using the following syntax:

bash
function_name() {
    # Function code
}

You can also use the function keyword to declare a function. Although it is not mandatory, some developers prefer it for greater clarity.

Example with both syntaxes ​

bash
#!/bin/bash

greet() {
    echo "Hello, $1"
}

function say_goodbye {
    echo "Goodbye, $1"
}

greet "World"
say_goodbye "User"

Output:

text
Hello, World
Goodbye, User

Calling functions ​

Functions are called by writing their name followed by parameters (if necessary):

bash
function_name parameter1 parameter2

Example with parameters ​

bash
#!/bin/bash

add() {
    result=$(( $1 + $2 ))
    echo "The sum of $1 and $2 is $result"
}

add 5 10

Output:

text
The sum of 5 and 10 is 15

Using the exit command ​

The exit command is used to terminate the execution of a script with an exit code. This is useful to indicate whether the script executed correctly or if an error occurred.

How to read the code returned with exit ​

The exit code generated by exit can be read with the special variable $?, which contains the result of the last executed command.

Basic example with exit ​

bash
#!/bin/bash

if [ $# -eq 0 ]; then
    echo "No arguments were provided."
    exit 1
fi

echo "Arguments received: $@"
exit 0

Execution: ​

bash
./script.sh
# Output: No arguments were provided.
# Exit code: echo $?
# 1

./script.sh argument1 argument2
# Output: Arguments received: argument1 argument2
# Exit code: echo $?
# 0

Using the return command ​

The return command is used inside functions to return an exit code. This is useful to indicate the result of an operation. Unlike exit, return only terminates the current function, not the entire script.

How to read the code returned with return ​

The code returned by return can be read with $? immediately after the function call.

Basic example with return ​

bash
#!/bin/bash

check_file() {
    if [ -e "$1" ]; then
        return 0
    else
        return 1
    fi
}

check_file "$1"
if [ $? -eq 0 ]; then
    echo "The file exists."
else
    echo "The file does not exist."
fi

Execution: ​

bash
./script.sh file.txt
# Output: The file exists.

./script.sh nonexistent.txt
# Output: The file does not exist.

Error capture with set -e ​

The set -e option allows a script to terminate immediately if a command fails. This is useful to ensure that errors are not overlooked.

Example with set -e ​

bash
#!/bin/bash

set -e

mkdir /nonexistent_directory

echo "This message will not be displayed if the previous command fails."

Command grouping with {} and () ​

In Bash, commands can be grouped to execute them in a single context.

Grouping in the same environment with {} ​

bash
{
    echo "First line";
    echo "Second line";
}

Grouping in a subshell with () ​

bash
(
    echo "This runs in a subshell."
    cd /tmp
    echo "Current directory: $(pwd)"
)

# The current directory does not change outside the subshell.
echo "Directory outside the subshell: $(pwd)"

Exercises ​

  1. Write a script that contains a function called multiply that receives two parameters and returns their product. Call the function with the values 4 and 5 and print the result.

  2. Write a script that contains a function called check_user that receives a username as a parameter. The function must check if the user exists in the system and return an appropriate message.

  3. Write a script that contains a function called list_directory that receives a directory as a parameter and lists its contents. If the directory does not exist, it must display an error message.

  4. Write a script that contains a function called evaluate_command that receives a command as a parameter, executes it, and displays whether the command was executed correctly or not.

  5. Write a script that contains a function called largest_number that receives three numbers as parameters and returns the largest of them. Call the function with the values 10, 20, and 15 and print the result.

  6. Write a script that contains a function called check_file that receives a filename as a parameter and uses return to indicate whether the file exists or not. Call the function and use $? to display the result.
